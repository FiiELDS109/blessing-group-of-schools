Designing Systems from Scratch: The Performance Web

Building fast, accessible, and visually sharp digital experiences from the ground up.

Web Design Team Lead: James Morgan Supervisor: Fidelis Omoni
Ad

Web design today demands fluency in both visual thinking and technical execution. The BGS Web Design track trains students to move confidently from a design brief to a fully responsive, performance-optimised website built with clean, semantic code. The goal is never just to make something look good — it is to make it work well, load fast, and remain accessible to every user on every device.

Students are introduced to the full front-end stack: HTML structure and semantics, CSS layout systems including Flexbox and Grid and JavaScript interactivity. They learn to read and write code with the same fluency they bring to visual design, because in professional practice the two are the same job — and pretending otherwise produces mediocre work.

Advanced modules cover web performance metrics, accessibility standards, SEO fundamentals, and the architecture of scalable design systems. Students learn to use browser developer tools to diagnose layout issues and to build component libraries that a developer can pick up and use without needing a lengthy explanation.

Several students have gone on to contribute to open-source projects, built and deployed personal tools with real users, and currently pursue aspirations in computer science and human-computer interaction — entering those fields with a practical foundation that gives them a head start from day one.
